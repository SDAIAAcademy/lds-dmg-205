# فئات المعلومات المحمية (إجراء هيئة صِيان)

هذه الفئات صياغة الهيئة الافتراضية لما تستثنيه سياسة حرية المعلومات من نطاقها. اذكر رقم الفئة في كل حجب.

1. ما يضر الإفصاح عنه بأمن الدولة الوطني أو سياساتها أو مصالحها أو حقوقها.
2. المعلومات العسكرية والأمنية.
3. ما حصلت عليه الدولة باتفاق مع دولة أخرى وصُنّف محميًا.
4. التحريات والتحقيقات والتفتيش والرقابة المتعلقة بجريمة أو مخالفة أو تهديد.
5. التوصيات والمقترحات والاستشارات لتشريع أو قرار حكومي لم يصدر بعد.
6. المعلومات التجارية أو الصناعية أو المالية أو الاقتصادية التي يؤدي الإفصاح عنها إلى ربح أو تجنب خسارة بطريقة غير مشروعة.
7. البحوث العلمية أو التقنية أو الحقوق، ومنها الملكية الفكرية، التي يمس الإفصاح عنها حقًا مشروعًا.
8. معلومات المنافسات والمناقصات والعروض التي يخل الإفصاح عنها بعدالة المنافسة.
9. ما يُعد مقيدًا أو شخصيًا بموجب نظام آخر، أو يتطلب الحصول عليه إجراءات نظامية معينة.

الحجب الجزئي: احجب السطر أو القيمة المحمية وحدها، واكتب مكانها `[محجوب: الفئة N]`، وأتح الباقي.
