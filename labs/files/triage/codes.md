# رموز سجل القرارات

اكتب في كل خانة رمزًا واحدًا من هذه الرموز، وسببك في عمود `reason` بالعربية.

## decision: القرار
| الرمز | المعنى |
|---|---|
| `approve` | موافقة على الطلب كما ورد |
| `approve_minimised` | موافقة بعد تقليص البيانات إلى الحد الأدنى اللازم للغرض |
| `reject` | رفض مسبب |
| `redirect` | إحالة إلى مسار آخر غير مشاركة البيانات من الهيئة |
| `await_consent` | إشعار الطالب بالحصول على موافقة الجهة المصدر أولًا |

## route: المسار
| الرمز | المعنى |
|---|---|
| `gov_platforms` | طلب عبر سوق البيانات ومشاركة عبر قناة التكامل الحكومية |
| `secure_channel` | وسيلة آمنة وموثوقة تحددها الجهات المختصة، لطالب غير حكومي أو حين يتعذر المسار الآلي |
| `ndb` | بنك البيانات الوطني، للطلبات لأغراض تحليلية |
| `open_data` | منصة البيانات المفتوحة: البيانات منشورة أصلًا |
| `foi` | مسار طلبات المعلومات العامة |
| `none` | لا مشاركة |

## instrument: الأداة النظامية
| الرمز | المعنى |
|---|---|
| `agreement` | اتفاقية مشاركة بيانات، لطالب غير حكومي |
| `controls_template` | نموذج ضوابط المشاركة، لطالب حكومي |
| `log_only` | تسجيل الطلب في السجل المخصص دون اتفاقية |
| `none` | لا يلزم شيء |

## signatory: الموقِّع
| الرمز | المعنى |
|---|---|
| `dmo_director` | مدير مكتب إدارة البيانات |
| `head_of_entity` | المسؤول الأول في الهيئة أو من يفوضه |
| `none` | لا توقيع |
