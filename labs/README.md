# مختبرات LDS-DMG-205

أربعة مختبرات ومهمة متابعة على حالة واحدة: هيئة صِيان للسلامة والصحة المهنية، جهة حكومية افتراضية. كل اسم وجهة ورقم وسجل في `files/` اصطناعي: أرقام الهوية تبدأ بالرقم 9، والسجل التجاري بـ CR-9، والجوالات بـ 0599، والبريد بنطاق example.org.

## ما تحتاجه

- جدول بيانات (LibreOffice Calc أو Microsoft Excel) ومحرر نصوص.
- [uv](https://docs.astral.sh/uv/) لتشغيل أدوات الفحص في `kit/`. الأدوات مكتوبة بمكتبة بايثون القياسية وحدها، ولا تثبّت أي حزمة، ولا تحتاج خادمًا ولا حسابًا ولا نموذجًا.
- الأوامر كلها تُشغّل من هذا المجلد (`labs`)، وكل ناتج يُكتب في `out/`، وهو مستبعد من المستودع.

```
uv run kit/indicators.py files/examples/indicators_example.json
```

إن طبع الأمر خمسة مؤشرات لملف المثال، فالتجهيز تام.

### في Google Colab

ارفع مجلد `labs` أو انسخ المستودع، ثم انتقل إليه، واكتب `python` بدل `uv run`:

```
!git clone <عنوان المستودع>
%cd <اسم المستودع>/labs
!python kit/indicators.py files/examples/indicators_example.json
```

أوامر `mkdir` و`cp` في صفحات المختبرات تُكتب في Colab بعلامة `!` قبلها.

## الذكاء الاصطناعي وسجل التصنيف

لكل ملف تصنيف في `files/register.csv`. لا يدخل أي أداة ذكاء اصطناعي توليدي ملف مصنف «مقيد» فأعلى. صفحة كل مختبر تعلّم الملفات «العامة» التي يجوز أن يراها المساعد (`class="ai-ok"`)، والتحقق يتأكد من أن كل ملف معلَّم «عام» في السجل.

| المختبر | دور المساعد |
|---|---|
| 1.1 | الفرز دون ذكاء اصطناعي؛ مرشد في الاتفاقية |
| 1.2 | مرشد: يسأل ويناقش، ولا يكتب القرار |
| 2.1 | مرشد: يشرح المقاييس ويقترح تعميمًا يجربه المشارك |
| 2.2 | يصوغ الخطابات من الملخصات العامة؛ الحجب والقرار والتوقيع للمشارك |
| المتابعة | يرى ناتج `out/indicators.md` المجمّع وحده |

## للمدرّب

```
uv run solutions/check.py            # كل المختبرات، ومهمة المتابعة، وقاعدة الذكاء الاصطناعي
uv run solutions/check.py 2.1        # مختبر واحد
uv run solutions/score_triage.py <سجل المشارك>   # تقدير سجل المختبر 1.1 مقابل المرجع
```

`check.py` يتأكد من أن ملفات البداية ما زالت تحمل مشكلاتها، وأن الحل المرجعي يجتاز الأدوات ويطابق المفتاح، ثم يحذف `out/`.

الملفات كلها يولدها مولد واحد ببذرة ثابتة (205)، فيعطي البايتات نفسها في كل تشغيل:

```
uv run --no-project _tools/prepare_files.py
```

النصوص والمفاتيح في `_tools/content.py`. إن غيّرت شيئًا فيها، أعد التوليد ثم شغّل `solutions/check.py`.

## الأدوات المرجعية

أداة `kit/risk.py` تحسب المقاييس التي يوثقها [ARX](https://arx.deidentifier.org/overview/privacy-criteria/) لنماذج الخصوصية، وسجل البيانات الوصفية يتبع حقول `package_create` في [CKAN](https://docs.ckan.org/en/latest/api/index.html). ARX وsdcMicro وCKAN وuData أمثلة قابلة للتبديل، ومن لديه إحداها يعيد الاختبار فيها على الملفات نفسها. إجراءات الهيئة في الملفات (المسارات، والمهل كما تقرؤها، وفئات الحجب، ومعايير النشر) قراءة الجهة الافتراضية للسياسات الوطنية، والمرجع نص السياسات.
