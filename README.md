# مشاركة البيانات والبيانات المفتوحة وحرية المعلومات

Data Sharing, Open Data and Freedom of Information

مسار التنفيذيين والقادة · أكاديمية سدايا · LDS-DMG-205 · المستوى 200

REPLACE: سطر واحد تحت العنوان: ما يستطيع المشارك فعله بعد المقرر

يتولى المشاركون مكتب الإتاحة في جهة افتراضية. فيفرزون طلبات المشاركة ويصوغون اتفاقية، ويبتّون في طلب بحثي، ويجيبون عن طلبات المعلومات مع حجب مبرَّر، ويعدّون مجموعة بيانات للنشر المفتوح مع اختبار لخطر إعادة تحديد الهوية والبيانات الوصفية والترخيص. ويُتناول تقويم الأثر في LDS-DMG-206، وإخفاء الهوية بعمق في DEV-SEC-303.

**الصيغة:** ورشة عمل: يومان مع مختبرات، ومهمة متابعة قصيرة

**صفحة المقرر:** https://sdaiaacademy.github.io/lds-dmg-205/

## نواتج التعلم

| | نواتج التعلم | المستوى | الدليل |
|---|---|---|---|
| LO1 | يطبق اختبار المشاركة على الطلبات ويصوغ اتفاقية لطلب معتمد، استنادًا إلى عشرة طلبات اصطناعية وقالب معد | Applied | سجل قرارات يطابق المرجع في ثمانية طلبات، واتفاقية تجتاز قائمة تحقق للبنود |
| LO2 | يقرر في طلب بحثي لسجلات مرتبطة وفق قواعد الاستخدام الثانوي، استنادًا إلى طلب وبيانات الجهة | Performance | مذكرة تحدد الشروط والضمانات ومسار الوصول، ويُدافع عنها في المراجعة |
| LO3 | يعدّ مجموعة بيانات للنشر المفتوح مع اختبار لخطر إعادة تحديد الهوية، على مجموعة بيانات لخدمة ما تحتوي على معرِّفات شبه مباشرة | Applied | الخطر قبل المعالجة وبعدها، وسجل بيانات وصفية تحقق من صحته |
| LO4 | يصوغ ردودًا على طلبات المعلومات مع تسجيل أسباب الحجب، استنادًا إلى خمسة طلبات والسجلات المتعلقة بها | Applied | خمسة خطابات تذكر أسباب أي حجب، وكلها ضمن المهلة |
| LO5 | يقيس أداء الإتاحة من أزمنة الاستجابة والاستخدام وإعادة الاستخدام، استنادًا إلى سجل الطلبات وإحصاءات التنزيل | Applied | تقرير يتضمن خمسة مؤشرات |
